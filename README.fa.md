# NetSpectra — آزمایشگاه پژوهشی پروتکل فینیکس

[English](README.md)

هدف پروژه، اندازه‌گیری بازتولیدپذیر TCP، TLS، QUIC و HTTP/3 در حضور اختلال و
DPI شبیه‌سازی‌شده است. ترافیک پیش‌فرض مصنوعی و مقصدها متعلق به آزمایشگاه هستند.
مشاهده، محاسبه، فرضیه و مجهول در نتایج از هم جدا می‌شوند.

## وضعیت فعلی

زیرساخت T01 تا T06 هفته اول پیاده‌سازی شده: ساختار مخزن، قالب همکاری، Python
با نسخه ثابت، تنظیم وابستگی‌ها، Ruff، pytest و فایل CI. بسته فعلی فقط شماره
نسخه دارد. قالب JSON برای Experiment و Run، نمونه‌های معتبر و نامعتبر و تست
اعتبارسنجی اضافه شده‌اند؛ [راهنمای قالب‌ها](schemas/README.md).
تست TCP/UDP فقط روی loopback اضافه شده؛ [روش اجرا](lab/README.md).
نصب محلی WSL هنوز مانده و Linux با CI بررسی می‌شود. سیاست محدوده و داده در
[ADR-001](docs/ADR/ADR-001-lab-scope-and-data-policy.md) ثبت شده و منتظر بازبینی مستقل است.
موتور آزمایش عمومی، API و داشبورد هنوز پیاده‌سازی نشده‌اند.

## اجرای محلی

Git و uv را نصب کنید و ترمینال را در پوشه پروژه باز کنید. نصب اولیه Python و
بسته‌ها دانلود دارد؛ خود تست اولیه هیچ ترافیک شبکه‌ای تولید نمی‌کند.

```sh
uv python install
uv sync --locked
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked pytest
uv build
```

نسخه Python در `.python-version` و نسخه‌ها و هش وابستگی‌ها در `uv.lock` ثبت
شده‌اند. دریافت Ruff و اجرای عادی `uv sync --locked` در ۲۰۲۶-۱۰-۳۱ موفق شد.
بررسی Ruff، قالب‌بندی و تست با فرمان‌های عادی قفل‌شده پاس شدند.
توسعه اولیه روی Windows ممکن است؛ آزمایش‌های namespace آینده به Linux یا WSL2
نیاز دارند. راهنمای ساختار پوشه‌ها در README انگلیسی است.
