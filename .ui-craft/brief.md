# NetSpectra operator panel

Audience: a Persian-speaking researcher running synthetic protocol experiments.
Primary decision: choose a configuration, run it and understand the outcome.
User direction: dark, modern, beautiful, simple and uncluttered; Persian RTL,
charcoal and soft green explicitly approved. Public IP access initially;
CDN/nginx later. Preserve working CLI and Git-only source synchronization.

Composition: restrained operator command surface, density 3, variance 3,
motion 2. One primary action per view. Experiment list, run history and a focused
result view; advanced execution policy is progressively disclosed.
Signature: focused run inspector showing outcome, attempt history and lineage.
No fake charts, pretend metrics or hard-coded test-success counts. Empty states
are truthful. Configuration exposes only implemented controls.

Stack: FastAPI plus buildless local HTML/CSS/JS; no established frontend to
replace. No external fonts, analytics or runtime CDN dependencies.
