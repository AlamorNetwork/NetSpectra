# W02 — local registry and run provenance

- Scope: T01–T06 implemented for independent review.
- T01: create/list/run/inspect commands with strict JSON validation and a
  single-user filesystem registry. Duplicate experiment IDs never overwrite data.
- T02: UUID run IDs, UTC timestamps, source SHA/dirty flag, tool/platform versions.
- T03: per-run configuration snapshot, summary, terminal record and artifact
  SHA256/size manifest; inspect detects changed artifact bytes and seed/identity
  mismatch with the snapshot. Writes use same-directory temporary files.
- T04: independent client/server subprocess endpoints for seeded TCP/UDP,
  same-host loopback only; no public bind, no namespaces or two-machine claim.
- T05: bounded per-attempt/total timeout, at most two retries, classified
  transient errors, attempt history and subprocess cleanup on cancellation.
- T06: SHA256-v1 seeded input plan, immutable snapshot replay and equality tests.
  Outcome/timing equality is not promised. No crash resume (planned later).
- Risks/limitations: nominal bandwidth label is not applied, no namespace
  isolation, single-user storage, dirty runs not publication evidence, abrupt
  termination/I/O errors may leave incomplete directories.

  smoke succeeds; source and wheel build succeed. Packaged schema resources
  are checked from the extracted wheel with installed runtime dependencies.
- Standalone isolated offline dependency resolution was unavailable for rpds-py;
  that failed attempt is not claimed as a successful clean wheel installation.
