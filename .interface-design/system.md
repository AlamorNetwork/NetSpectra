# NetSpectra interface system

## Working brief
The operator speaks Persian, reads RTL, prefers calm dark tools and needs one
bounded next action. They register SSH nodes, choose a client/backend path, run
synthetic traffic, and inspect actual success/failure evidence. Avoid competing
controls and long ungrouped reports. Preserve the independent workspaces.

## Domain exploration
Domain: endpoint, SSH identity, selected path, handshake, echo sample, capture,
client/backend/relay, immutable evidence. Color world: charcoal console casing,
graphite workbench, pale cable labels, muted mint indicator, amber caution lamp,
desaturated coral failure marker. No decorative gradients or fabricated telemetry.
Signature: a neutral endpoint-to-endpoint route trace, ordered RTL, with explicit
client/relay/backend labels, shared by saved paths, form preview and reports.
Rejected defaults: generic KPI card grid -> evidence-first lists; five equal node
buttons -> connection check plus disclosed setup tools; tiny metadata everywhere
-> 14px reading text with 12px metadata and deliberate weight contrast.

## Direction and component checkpoint
Intent: let an operator prepare a node, run a path, or identify a failed sample
without scanning unrelated setup controls. Feel: quiet instrument workbench.
Hierarchy: server identity on node cards; endpoint trace on paths; real outcome
and sample timings in results. One filled mint primary page action.
Palette: console-canvas #111617, console-surface #171d1f, console-raised #202729,
label-primary #eef1ed, label-secondary #b3bfba, label-muted #8e9c96,
signal-mint #b4d7ba, signal-failure #edaaa3, signal-caution #e3c18b.
Depth: subtle surface shifts; borders rgba(235,245,238,.08). Sidebar and canvas
share a background. Inputs inset #0e1314; no heavy shadows, glossy gradients,
large decorative numbers or imaginary health indicators.
Typography: existing local Vazirmatn; body 14/400, metadata 12/400, controls 13/500,
section 18/600, page 28/600. Tabular numbers, LTR-isolated IP/port/IDs.
Spacing: 4px base, 8/12px micro gaps, 16/24px component padding, 32/40px sections.
Density: readable workbench; 44px controls, minimum 40px compact controls.
Radius: 6px controls, 12px panels, 16px dialogs.

## Patterns
Node: identity/address first, SSH identity fact (not online claim), connection check
and settings visible, fresh installation/key/dependencies in native details.
Path: real role labels and names on neutral route trace; protocol/port/seed metadata;
run with capture as primary path action and plain run secondary.
Results: outcome text plus semantic dot; bounded error copy, readable sample table;
PCAP evidence and identifiers disclosed separately, all downloads retained.
Native button/link/select/details/dialog; keyboard focus and reduced-motion honored.
Mobile: <=800px collapsed sidebar; single-column nodes and wrapping route trace.
No body-level horizontal overflow. Keep working links, filters, pages and reports.
